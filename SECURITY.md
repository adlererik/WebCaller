# Reporting security problems

Do not post secrets, private setup links, messages, production logs or vulnerability exploit details in a public issue. Use GitHub’s private vulnerability reporting for this repository when enabled. If it is unavailable, contact the repository owner through a private channel before sending details.

WebCaller is an unaudited preview. Read the [security model](docs/SECURITY.md), [13 October 2026 source review](docs/SECURITY_REVIEW.md) and [Signal comparison](README.md#webcaller-beside-signal). The core library, tests and maintainer-assisted review do not constitute an independent audit of the application or its custom SAS. There is no promised security-support timeline or audit.
