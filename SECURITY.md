# Reporting security problems

Do not post secrets, private setup links, messages, production logs or vulnerability exploit details in a public issue. Use GitHub's private vulnerability reporting for this repository when enabled. If it is unavailable, contact the repository owner through a private channel before sending details.

v0.2.0 is an unaudited preview. See [the security model](docs/SECURITY.md) for what it does and does not protect. There is no promised security-support timeline or audit.
