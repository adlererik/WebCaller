# Reporting security problems

Do not post secrets, private setup links, messages, production logs or vulnerability exploit details in a public issue. Use GitHub’s private vulnerability reporting for this repository when enabled. If it is unavailable, contact the repository owner through a private channel before sending details.

This is an unaudited libsignal/PQXDH browser experiment. Read the [security model](docs/SECURITY.md), [experimental source review](docs/SECURITY_REVIEW.md) and [Signal comparison](README.md#forward-secrecy-mitm-and-comparison-with-signal). Official libsignal does not certify this browser/storage/signature adapter, application or custom SAS. Tests/maintainer review are not an independent audit. No security-support timeline is promised. Do not import stable Olm accounts or treat this branch as an unreviewed production upgrade.
