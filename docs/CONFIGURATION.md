# Configuration reference

Use [native installation](INSTALL_NATIVE.md), the release-matched [Docker bundle](../docker/README.md), or a source build. Fresh setups select `WEBCALLER_CRYPTO_ENGINE=libsignal-pqxdh-v1`; there is no runtime switch back to Olm. Existing Olm data requires an explicit backed-up migration.

Copy `.env.example` or use the installer/setup command. `.env` is private, ignored by Git and never copied into the image/release. Values are plain `KEY=value`; use single-line values without surrounding quotes in the supplied helpers. Never paste the file into an issue.

| Variable | Purpose |
|---|---|
| HOST | Native HTTP bind, default loopback. Compose overrides to 0.0.0.0 inside the container |
| PORT | `.env.example` uses separate native port 8088; Compose uses internal 8080 |
| WEBCALLER_CRYPTO_ENGINE | Explicit libsignal-pqxdh-v1 transport selection, set by new setup/Docker defaults; do not silently reuse Olm state |
| WEBCALLER_TEST_INSTANCE | Legacy isolated preview startup flag libsignal-preview-v1; accepted for existing previews, not needed for a new release installation |
| PUBLIC_URL | Canonical full HTTPS origin/path, e.g. https://calls.example.com/calls with your own domain substituted; determines allowed Origin and path |
| APP_PATH_ALIASES | Optional comma-separated previous paths on the same origin, e.g. /calls when PUBLIC_URL ends in /com; share the existing accounts and service |
| APP_RETIRED_PATHS | Optional comma-separated removed paths, disjoint from active paths. The website bridge returns 404 without revealing the replacement. Open the new address on each phone so it can migrate permitted browser alerts. |
| APP_MANIFEST_ID | Optional original absolute app directory, e.g. /calls/, retained during a path move so the installed web app keeps its manifest identity |
| DATA_DIR | SQLite directory; Compose overrides to /app/data in its named volume |
| BOOTSTRAP_TOKEN | Generated 24-byte random first-owner bearer secret; private QR hides typing, not its sensitivity |
| VAPID_PUBLIC_KEY | Generated public browser push key |
| VAPID_PRIVATE_KEY | Generated private push signing key; preserve with its paired public key |
| VAPID_SUBJECT | Your real operator contact URL or mailto address for push, not someone else's address |
| CF_TURN_KEY_ID | Optional Cloudflare Realtime TURN key ID |
| CF_TURN_API_TOKEN | Optional private provider API token; backend takes precedence when both CF fields exist |
| TURN_URLS | Comma-separated turn:/turns: URLs for a REST-shared-secret relay |
| TURN_SECRET | Long private REST HMAC secret shared with coturn; generated by setup and never given to browsers |
| TURN_TLS_PORT | External TLS port for advanced native config, default 5349; 443 requires a separate sharing plan |
| WEB_HOST | Hostname used by optional Caddy, without scheme/path |
| APP_PORT | Host loopback HTTP port mapped to the app's internal 8080 |
| TURN_PUBLIC_IP | Globally routable IPv4 for the self-hosted relay container |
| TURN_LAN_IP | Fixed LAN IPv4 behind a home router; empty on directly public VPS |
| ATTACHMENT_USER_QUOTA_MB | Pending/completed file plaintext-size reservation per sender, default 1024 MB |
| ATTACHMENT_GLOBAL_QUOTA_MB | Total reserved file size on this server, default 4096 MB |
| MAP_TILE_URL | Optional public HTTPS `{z}/{x}/{y}` tile template, or same-origin path; defaults to OpenStreetMap |
| MAP_TILE_ATTRIBUTION | Visible copyright text for the selected tile provider; default © OpenStreetMap contributors |
| MAP_TILE_ATTRIBUTION_URL | HTTPS copyright/license page shown with map cards |
| TURN_REALM | Coturn auth realm, default webcaller |
| NTFY_PUBLIC_URL | Optional separate HTTPS ntfy origin shown to phones, e.g. https://ntfy.example.com; no topic/path or credentials |
| NTFY_PUBLISH_URL | Fixed server-side ntfy publishing endpoint; HTTPS or loopback HTTP by default; the prebuilt stack has an explicit exact-host private-network exception |
| NTFY_PUBLISH_TOKEN | Private write-only publisher credential; generated by the optional installer, never given to phones |
| NTFY_PUBLISH_TOKEN_FILE | Alternative to the inline token; prebuilt Docker reads its read-only publisher volume. Do not set both token forms |
| NTFY_ALLOW_DOCKER_HTTP | Default false; true permits only `http://ntfy:8094` on the prebuilt stack’s isolated Docker network; never enables arbitrary plaintext destinations |
| NTFY_IOS_UPSTREAM | Default false; set true only when ntfy itself has the stock iPhone wake-up relay configured |

`npm run setup` fills missing owner/relay/VAPID secrets and preserves existing values. An incomplete VAPID pair is rejected; do not rotate half of it. App `.env` changes require container recreation/restart. Native systemd uses the EnvironmentFile; restart that service too.

Compose profiles: default starts only the app; `--profile https` adds Caddy; `--profile turn` adds the Linux-host-networked relay. They can be combined. `.runtime/compose-profiles` is the private installer selection, not a public config file.

Each file is limited to 200 MB. Quota values must be integers from 10 to 65536 MB; ciphertext tags and SQLite overhead consume additional storage.

Map configuration is public through `/api/config`; never put secret keys in these values. Select a provider whose terms permit browser tile previews, anonymous CORS canvas rendering and expected traffic. Set its required attribution text/URL together with the template. The default requests only displayed tiles with normal cache behavior and an origin referrer; no offline/bulk downloads. OpenStreetMap’s community tile service has no availability guarantee or paid subscription in this project. For larger deployments choose a suitable provider or self-host. See the [tile usage policy](https://operations.osmfoundation.org/policies/tiles/).

## Optional extra ringing

Leave `NTFY_PUBLIC_URL`, `NTFY_PUBLISH_URL` and `NTFY_PUBLISH_TOKEN` all empty to use only normal Web Push. Enabling ntfy requires all three together; a partial configuration fails startup. `NTFY_IOS_UPSTREAM` describes the ntfy server's actual upstream setup rather than configuring it. Phone subscriptions have their own random read-only addresses, not the publisher token or a shared password. See [Extra ringing](EXTRA_RINGING.md) for setup, isolation, retention and the iPhone wake-up limitation.

## Prebuilt Docker reference

The [Docker bundle](../docker/README.md) separates release-pinned `images.env` from private `.env` installation choices and `config/app.env`, `config/turn.env`, ntfy/proxy configuration and a private optional connector-token file. App data, ntfy auth state and its publisher credential use separate persistent volumes; ntfy never mounts the app database or app environment. Use the supplied wrapper so both environment files are loaded. The setup wizard refuses existing configuration; upgrades preserve it.

## Personal calling codes

`DIAL_CODES_ENABLED` defaults to `true`. Each existing device remains unlisted until it chooses a code under Settings. Set it to `false` to disable code enrollment and code changes while preserving invitations and existing conversations. Codes enable new guest identities and limited contact requests; review [the calling-code guide](CALLING_CODES.md) before sharing codes publicly.

## File limit and storage upgrades

The per-file maximum is **200 MiB (209,715,200 bytes)**, shown as 200 MB in the UI. Fresh defaults reserve 1024 MiB per sender and 4096 MiB globally; these are totals across pending and committed files, not extra capacity per conversation. Disk use also includes ciphertext tags, database pages and journal overhead. Set limits for your available disk. A lower existing configured quota is preserved and may prevent a 200 MB file from being accepted.

When upgrading an older source installation whose private `.env` explicitly says `ATTACHMENT_USER_QUOTA_MB=100`, change it to `1024` (or another suitable value at least `200`) if you want full-sized files. The global quota must also have enough free reservation. For the prebuilt stack edit `config/app.env`, then run `./webcaller start` to recreate the app with the new environment. For native systemd, restart the existing service after changing `.env`. Preserve all owner, push, TURN and ntfy credentials. No change to proxy upload limits is needed for the app's small chunk requests; each HTTP body remains at most 65,552 bytes.

## Guided Docker configuration

For v0.20.0 Linux bundles, prefer `./webcaller configure` to hand-editing files. The private `.env` stores the persistent `COMPOSE_PROJECT_NAME`, service profiles and host-side loopback ports; `config/app.env`, `turn.env`, `ntfy.yml`, `Caddyfile` and `tunnel-token` hold the generated configuration. The helper preserves owner/VAPID credentials and project identity when reconfiguring; it does not reset phone identities. Configuration, snapshots and tokens must not be committed or copied into a public source tree. Changing a hostname changes the browser origin and may require phone setup again. [Linux guide](../docker/README.md).
