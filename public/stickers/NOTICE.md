# Bundled sticker artwork

These are curated five-sticker starter packs from public Telegram sticker catalogs. The original artists and character rightsholders retain copyright. The application code license does not grant a license to this third-party artwork. These are community packs, not official endorsements. No external catalog, analytics, advertisement, or image CDN is contacted by the installed picker.

Each sticker in catalog.json records its source URL, SHA-256, original dimensions and byte size. Files are bundled unchanged as WebP. Recent/favorite selections use encrypted device storage.
